# Budget Bro

A learning project where I am building my C# and TypeScript
full stack foundations through a budget tracker.

## Learning goals

- Understand C# fundamentals.
- Build an API with ASP.NET Core.
- Learn TypeScript and connect a frontend to the API.
- Store data in a database.
- Use Docker and deploy the application.

## Current progress

- Created the BudgetBasics console application.
- Used Console.WriteLine to display welcome messages.
- Learned how to run the application with dotnet run.

## How to run

Requires the .NET SDK.

From the repository root:

    cd BudgetBasics
    dotnet run
